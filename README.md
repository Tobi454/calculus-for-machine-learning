# Calculus for Machine Learning

This repository contains my notes and Python examples from the Calculus section of my Mathematics for Machine Learning roadmap.

## Topics Covered

- Functions and limits
- Derivatives and differentiation rules
- Partial derivatives
- Gradients
- Optimization: minima and maxima
- Gradient descent using Python

## Tools Used

- Python
- NumPy
- Matplotlib
- Jupyter Notebook

The goal of this section was to understand how calculus concepts connect to machine learning, particularly how gradients and optimization help models minimize their loss during training.
